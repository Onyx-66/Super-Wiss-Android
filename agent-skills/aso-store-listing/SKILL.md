---

CORE PRINCIPLE: none of the polish in your other skills matters if the store listing doesn't convert a browsing user into an install. Treat the listing as its own design surface, not an afterthought after the game is done.

ICON DESIGN:
- Must be legible and recognizable at the smallest rendered size (as small as ~24dp in some launcher contexts) — test at that size, not just at the large preview size in your design tool.
- Should feature the SAME pixel-art style and color palette as the actual in-game UI (ties to mobile-pixel-art-ui-ux skill) — an icon that looks like a different, higher-fidelity art style than the actual game is a well-documented cause of negative first-session reviews ("not what I expected") and increased uninstall rate, even if the actual game is good.
- Avoid small text in the icon — it's unreadable at launcher size and wastes the limited visual space needed for a strong silhouette/character read.
- Feature the game's most recognizable single character or symbol, not a busy scene — a strong single silhouette outperforms a detailed composition at small sizes.

SCREENSHOTS (in order of priority — Play Store shows these before video):
1. First screenshot must show actual core gameplay (combat/movement in action), not a menu or logo screen — this is the single highest-impact screenshot slot.
2. Include at least one screenshot showing character/roster variety if the game has multiple playable characters (ties to character-narrative-skills-pets skill) — roster variety is a strong conversion driver for character-collection-adjacent games.
3. Include one screenshot showing a boss fight or high-intensity moment if present — spectacle sells better than calm gameplay in store listings.
4. Avoid screenshots that are dominated by UI/HUD elements or clearly show a shop/monetization screen as a primary image — this can suppress conversion versus gameplay-forward screenshots.
5. Add short text captions overlaid on 2-3 screenshots calling out a key feature ("Boss Rush Mode," "10 Playable Heroes") — captioned screenshots consistently outperform uncaptioned ones in Play Store conversion data across the industry.

DESCRIPTION & KEYWORDS:
- First 1-2 lines of the description are the most important — they show before the "read more" cutoff and function similarly to the icon/first screenshot in impact; lead with the core hook (genre + unique feature), not a studio name or generic praise.
- Include genre and mechanic keywords naturally in the description (e.g. "pixel art," "action platformer," "boss fights," "local multiplayer") since Play Store search indexing weighs listing text — don't keyword-stuff unnaturally, but don't omit obvious descriptive terms either.
- Keep the description scannable: short paragraphs or bullet-style feature lists outperform dense paragraphs for a mobile audience reading on a store page.

APP NAME:
- Keep the visible app name (shown under the icon on the home screen) short and memorable — long names get truncated on the home screen launcher grid, which can look unpolished or make the app hard to find later.
- A short descriptive suffix in the FULL Play Store title (not the home-screen name) can aid search discovery (e.g. "GameName: Pixel Action Platformer") — check current Play Console title-length limits before finalizing, as these are enforced hard character limits.

WHEN PREPARING A STORE LISTING:
1. Confirm the icon uses the same art style as actual gameplay, not an idealized/different-style promotional version.
2. Confirm the first screenshot is real gameplay, not a title/menu screen.
3. Confirm the first 1-2 description lines lead with genre + hook, not preamble.
