# Versioning

GitHub semantic versioning starts at **v1.0.0**.

The earlier “2.0”, “3.0” and “4.0” labels were internal development-iteration names,
not GitHub releases. They therefore do not require this repository to begin at v4.

From this baseline:
- bugfix / packaging-only release → v1.0.1
- backward-compatible feature release → v1.1.0
- intentionally breaking major release → v2.0.0
