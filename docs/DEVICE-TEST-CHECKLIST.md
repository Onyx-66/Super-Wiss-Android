# Ascension 1.1.0 — phone test checklist

All entries below are **pending physical testing**, not claimed passes.

## Install/update and offline
- Keep a backup of valuable prior local progress. Install the update without uninstalling.
- Confirm launcher says Super Wiss Ascension, landscape launch/loading page and new home.
- Test airplane-mode solo play, audio toggles, background/resume, call interruptions and mute.
- Verify old gold/unlocks remain; buy a free outfit, change controls, force-stop/reopen and confirm
  persistence. Do not reset application storage during a persistence check.
- Test pause, all controls, wall slide/jump, sword, knife, both hero skills and stamina/focus limits.
- Enter Pets practice for Wolf/Dragon/Orca and confirm buffs STOP at their advertised expiry.
- Test low battery/performance mode on a low-end and high-refresh phone; note frame pacing,
  heat/battery, audio latency, long levels, notched screens, rotation and simultaneous touches.

## Four control layouts
- Drag/resize/opacity-adjust controls in slot1, save, alter slot2 and verify no cross-over.
- Move Pause using X/Y selector when covered. Test Analog/Arrows and Mirrored.
- One-tap cycle all four in game. Check no accidental overlap; restore default if necessary.

## Paired Bluetooth
- Install same version on2 phones, pair first, allow Nearby devices, create host room.
- Wrong code must not join. Correct6 digits including leading0 must join.
- Host Start stays disabled until minimum players/ready state. Option changes reset ready.
- Fight same boss, check identical HP/phases and visible ally. Down one player; hold revive3s.
- Repeat with3 then4 phones. Test FFA and exactly-four2v2/friendly-fire rules.
- Test rematch, host kick, permission denial, wrong-code attempts, disconnect, radio off,
  reconnect-lobby slot reuse, background cancellation and coexistence with headphones.
- Record device models/Android/WebView versions and observed latency, not just a pass label.

## Profiles/accounts (only after staging server deployment)
- Configure HTTPS, signup/login/recovery, friends, profile avatar/frame, deletion web path.
- Confirm no tokens/passwords are exposed in local Bluetooth roster, logs or shared room text.
- Operate reporting/moderation before public testing. No fake server success is expected offline.

## Experimental camera
- Enter Settings camera lab, try multiple worlds, exit back to side view.
- Confirm practice-only labeling and no rewards/ranks; report unreadable corridors or nausea.

Keep exact install error messages/crash logs. Do not disable Play Protect to hide a failure.
