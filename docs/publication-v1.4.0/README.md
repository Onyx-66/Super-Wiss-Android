# v1.4.0 source publication

This publication imports the previously delivered Atelier WIP as ordinary repository files and synchronizes version labels to 1.4.0 / Android code 45. No user data, private signing material or font binaries are included. Existing tags and save/application identities are preserved.

`TRANSFER-INVENTORY.json` records the transferred delta against the original source candidate; generated web/native assets are freshly built before the source commit. Root .gitignore and unrelated existing repository files are preserved. The old implementation diffs retain their original baseline and do not purport to include this release-metadata bump. Current-run source test logs are stored here. A separate Android Actions run is required for compiled packages.
