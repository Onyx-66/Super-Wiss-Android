# 3.0.0-playtest — Companion Chronicles

24 September 2026. Package version code 30; offline QA.

## Added

15 worlds at exactly 5× their previous tile-column counts; populated sectors and
additional checkpoints; 16 hero skills; Wissem crowd fury; 7 collectible pets;
Dragon/Orca active abilities; 13 enemy types; 14 power-ups and multiple sources;
27 original recorded sound cues and five music loops; art from the approved boards;
new rotating coins, block-texture atlases and Wissem launcher icon; pet sanctuary
and practice tests; separate volume controls; editable JSON registries and asset
manifest; map-authoring helpers and a full replacement/rebuild guide.

## Preserved

Landscape play, offline campaign stars, missions/daily practice, local records,
endless looping, touch controls, pause, keyboard/gamepad mappings and the existing
native WebView packaging architecture.

## Save changes

V2 gold, XP, settings, hero selection aliases and cleared-world unlocks migrate.
Previously cleared worlds retain only their clear star. Long-map scores, times,
extra objectives and endless records start fresh. V2 storage remains untouched.
No cloud save and no exact mid-run snapshot resume.

## Scope

Actual signed APK included. Android Studio project included but not compiled via
Gradle here. No AAB. No Android device/emulator run. No active online services.
Detailed character images are single-pose art with procedural motion; replacement
animation sheets are supported but not supplied as complete hand-animated sets.
No Mario sprites/recordings, Minecraft textures or watermarked stock images bundled.

See TEST-REPORT.md for executed verification and DEVICE-TEST-CHECKLIST.md for phone QA.
