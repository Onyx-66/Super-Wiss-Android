# Privacy notice worksheet — NOT ready to publish

Replace [PUBLISHER], [CONTACT], [POLICY URL], [SERVICE LOCATION], [RETENTION] and the date
with real operator information. Have the final text reviewed for your jurisdiction and

**Offline game:** campaign saves, settings, heroes, pets, local records and a guest
profile remain in application storage. There is no ad/analytics SDK. Uninstalling or
clearing storage removes local data. There is no cloud-save feature.

**Nearby play:** when explicitly used, paired phones exchange player cards, inputs and
host-computed game state over Bluetooth. No account password/session token is included.
Nearby device names/addresses are used to connect; the game does not scan for location.
The host may see the guest's selected public player card. All participants should know
which nearby person is hosting. No public Internet leaderboard receives these results.

**Optional online accounts:** [PUBLISHER] operates [SERVICE]. The service stores username,
salted password hash, hashed recovery code/session tokens, friend code, selected profile
cosmetics, accepted friendships, requests, blocks and reports. No email is collected.
The server handles connection IPs transiently for rate limiting; determine and disclose
any reverse-proxy/hosting logs and processor policies. Tokens are kept locally for login.
Specify hosting locations/processors and the legal basis appropriate to your operation.

**Deletion/recovery:** users can delete accounts in Profile or at [SERVICE]/delete-account.
This removes online profile, sessions and relationships. Local phone progress is separate.
Reports retain reason/status with deleted account IDs nulled. Specify [RETENTION] for
reports, logs and backups, explain why anything remains, and actually enforce that policy.
Recovery requires the once-shown recovery code. No email password reset is available.

**Safety:** provide [CONTACT] for reports, privacy questions and data requests. Implement
staff review and escalation. Explain the actual audience/age approach. Do not make an
unsupported claim that no personal data is collected merely because the main game is offline.
