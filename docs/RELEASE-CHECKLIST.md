# Release gates — not a Play Store submission

Ascension1.1.0 is QA-signed, not a production release. Guilds stay deferred.

Before production: compile/lint with official Android SDK/Gradle; verify APK with official
apksigner; install/update and exercise native features on physical devices; benchmark battery,
thermals/frame pacing; balance later bosses with humans; test2/3/4-phone Bluetooth; audit
account/bridge/security and rate limits; deploy HTTPS with persistence, backups, deletion and
moderation; choose a final application ID and private signing/upload key; prepare accurate
current PlayConsole privacy/data-safety/content-rating/testing declarations.

Art rights must be checked for every future addition. Current community credits are bundled.
Unknown input Icons are excluded. No real-money shop, analytics, ads or cloud save is enabled.
Do not add package padding to imply quality. Current outfits are palettes, not a modular
clothing library. Screenshots in docs are browser captures, not device/Play approval.

No AAB, public deployment, verified global leaderboard, production-account audit, viral-growth
guarantee or official-device certificate is part of this test delivery.
